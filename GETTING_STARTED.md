## 🚀 Démarrage immédiat

### 1. Configuration API
```bash
# Éditer .env.local
OPENAI_API_KEY=sk-votre_cle_openai
```

### 2. Démarrer le serveur
```bash
cd my-app
npm install  # une seule fois
npm run dev
```

### 3. Ouvrir
```
http://localhost:3002
```

### 4. Tester
- Uploadez le fichier `test-file.txt`
- Attendez l'analyse
- Consultez le rapport

## 📞 Support rapide

### Erreur "Clé API invalide"
→ Vérifiez votre clé dans `.env.local`

### Port déjà utilisé
→ Changez le port: `PORT=3003 npm run dev`

### Fichier trop volumineux
→ Max 10MB par fichier

### Compilations lentes
→ Supprimer `.next`: `rm -rf .next`
